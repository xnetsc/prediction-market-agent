# 时区信息延迟案例研究

网络流传案例不是“小额高频”策略。报道转述的是一次事件驱动的批量机会：Agent 连续运行九天后，
在美国夜间提示六个即将于 90 分钟内结算的市场，并请求人工批准一笔合计 12,000 美元的仓位。
报道本身也记录了对截图、收益真实性和推广动机的质疑，因此代码将其当作待验证的策略假设，而不是
可复制收益证据。来源：[NDTV 对原始社交媒体帖文及争议的转述](https://www.ndtv.com/feature/x-user-claims-ai-agent-turned-rs-11-lakh-into-rs-40-lakh-while-he-slept-internet-reacts-11221684)。

由此形成的 `timezone_latency` 策略只保留可检验部分：寻找临近结算、信息在非美国时区先公开、盘口可能
滞后的市场；要求核对合约文本、命名结算源、发布时间、价差、费用、深度及平台特殊规则。策略文本明确
排除泄密、截图和循环报道，并在证据不足时 HOLD。它不会把报道的绝对下注额复制到机器人，实际额度全部
交由当前组合风控插件决定。

研究结果也不支持“只要用 AI 或增加研究量就能稳定盈利”。一项 57 天真实资金基准发现不同模型和平台
结果差异很大，且研究量与结果没有相关性；这支持本项目保存逐笔决策、可执行盘口和事后对照，而不是仅看
模型解释。[Prediction Arena 预印本](https://arxiv.org/abs/2604.07355)。另一篇研究强调预测优势还需要
适当下注映射并计入流动性损失，进一步说明“发现新闻”并不自动等于可成交利润。
[When do prophets profit in prediction markets?](https://arxiv.org/abs/2607.06166)。

## 「信息不足」不是结论

决策阶段的框架业务工具预算原来是 **4 步**，而模型还要核对盘口、K 线、跨平台比价、业务历史和账务。
通用搜索、网页、文件和 skills 由官方 CLI 自己管理，不计作框架自造工具。四步连业务核验都不够，于是结论会普遍变成「信息不足,所以观望」—— 那不是
判断,是没得查。默认已提到 **12**,上限 40。

策略文本里也写明了这件事:信息不足是每次决策的**起点**,不是发现。HOLD 经常是对的(多数市场定价大致
正确),但它要来自查过之后确立的东西,而不是没查的东西。跑完预算仍判断不了,就说出**还没答上的那个问题**
和下一步本来要读什么 —— 那是下一轮唯一能接着做的东西。

## 何时再看、看什么,由 AI 定

两件原来都是写死的:插件配置里的扫描间隔是固定值,而采集哪些标的完全由插件的固定排序决定
(Polymarket 是 `order=volume&ascending=false`)。

现在这两样都由发现阶段的同一次模型调用一起给出(不额外花调用):

| 字段 | 含义 |
| --- | --- |
| `next_scan_seconds` | 多久之后再看这个平台。**插件的间隔是下限**——可以要求等更久,不能要求更早回来 |
| `next_survey_queries` | 下一轮除了平台自己的列表之外,还要去搜什么(走 `search_market_candidates`,不改契约) |
| `pacing_reason` | 一句话说明为什么,好让下一轮能判断这个猜测准不准 |

**下限归插件**:多久愿意被问一次是它对自己和平台限流的了解,框架只把 AI 的请求转达过去,插件取两者
较大的那个。不去问这个服务的插件,行为和以前完全一样。

**搜到的标的是加在列表之上,不是替换它。** 平台列表是一个固定的意见(成交量最高的在前),只看它的机器人
也只能在那里找到东西;但一个找不到东西的查询不该让这一轮变空。查询失败同理:记一条警告,继续。

计划存在数据库里而不是进程内存里 —— 存在内存里,重启后会悄悄退回固定节奏和固定列表,而"采集悄悄回到
默认"这个症状,和"AI 就是要默认"根本分不出来。

## 决策依据的语言

模型写给人看的文字默认是**中文**（应用设置 `agent_language`，可选 `zh` / `en`）。覆盖的是所有会被人读到
的散文：决策理由、选中某个标的的原因、这一轮为什么跳过、为什么要资金（这条批准的人要读）、反问答复里
给你的说明。

**只影响散文。** 字段名、`BUY`/`SELL`/`HOLD`/`MARKET`/`LIMIT` 这类枚举取值、工具名、ID、代号、URL 和一切
数字都按 schema 原样保留——翻译它们会让程序读不懂自己的答案。标的自身的措辞按**原文**引用，因为结算认的
是原文，不是译文。

实现上只有一处：它接在每个提示词共用的前言后面，所以一个设置同时管到决策、发现轮次、资金请求和反问。
策略正文、工具契约和 schema 仍是英文——那些是给模型的指令，不是给人读的东西。

选 `en` 时**不追加任何内容**：英文本来就是 schema 和策略的语言，再说一遍只是噪音。
